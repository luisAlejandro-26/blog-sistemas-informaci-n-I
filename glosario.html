D

  • Dato

    Representación simbólica (letras, números o símbolos) de un hecho, evento o entidad. El dato es la materia prima sin contexto ni significado por sí mismo.

  • Diccionario de Proyecto

    Documento de control donde se registran definiciones de datos, estructuras, flujos y procesos. Si un término no está en el diccionario, no existe en el proyecto. Ver Fase 3.

I

  • Información

    Datos procesados, organizados y dotados de significado que resultan útiles para la toma de decisiones. La información reduce la incertidumbre.

  • Integridad referencial

    Propiedad que garantiza la consistencia de las relaciones entre tablas mediante claves foráneas. En PETPULSE se aplica con ON DELETE CASCADE.

J

  • JAD / DCA — Desarrollo Conjunto de Aplicaciones

    Metodología colaborativa que reúne a desarrolladores, analistas y usuarios finales desde las primeras etapas para definir requerimientos y validar funcionalidades. Ver Fase 1.

P

  • Procesamiento de Datos

    Conjunto de operaciones (clasificación, cálculo, resumen, almacenamiento) que transforman datos crudos en información útil y estructurada.

  • PIECES

    Marco de referencia para analizar problemas desde seis perspectivas: Performance, Información, Economía, Control, Eficiencia y Servicio. Aplicado en PETPULSE para diagnosticar el control veterinario tradicional.

S

  • Sistema

    Conjunto de elementos interrelacionados que interactúan entre sí para alcanzar un objetivo común. Un sistema puede ser físico, lógico o social.

  • Sistemas de Información

    Conjunto organizado de recursos (personas, tecnología, procesos) que recoge, almacena, procesa y distribuye información para apoyar la toma de decisiones y el control en una organización.

Clasificación funcional de sistemas

  • SPO / TPS — Procesamiento de Operaciones

    Registro de operaciones cotidianas. En PETPULSE: registro de mascotas, citas, historial y autenticación.

  • SIA / MIS — Sistema de Información Administrativa

    Reportes y control centralizado. En PETPULSE: reportes clínicos y generación de PDF.

  • SSD / DSS — Soporte a Decisiones

    Herramientas que apoyan decisiones complejas. En PETPULSE: alertas preventivas e identificación de razas con IA.

  • SAO — Soporte de Actividades de Oficina

    Gestión de documentos y agenda. Facilita automatización de oficina, manejo de correspondencia y flujos administrativos.

  • SSE — Sistema de Información para la Alta Dirección

    Dashboard ejecutivo con indicadores clave (KPIs) en tiempo real para monitoreo organizacional.
